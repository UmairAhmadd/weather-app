# 🌦️ Weather App

A responsive weather app built using HTML, CSS, and JavaScript.

## 🚀 Features

- Search weather by city name
- Real-time weather using OpenWeather API
- Temperature display
- Humidity and wind speed
- Responsive modern UI

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- OpenWeather API
